#Algorithm

Create a Horse class

    Set each horse's position to 0

    Create move function
        Generate a random number of 0 or 1
        Add the random number to the horse's position

    Create isWinner function
        If the horse's position is greater than or equal to 15
            Return true
        Otherwise
            Return false

Create 3 horses:
    Horse 1
    Horse 2
    Horse 3

Start the random number generator

WHILE Horse 1, Horse 2, AND Horse 3 have not reached position 15

    Ask the user to press Enter to continue

    Move Horse 1
    Move Horse 2
    Move Horse 3

    Display Horse 1's position
        Print spaces based on Horse 1's position
        Print Horse 1

    Display Horse 2's position
        Print spaces based on Horse 2's position
        Print Horse 2

    Display Horse 3's position
        Print spaces based on Horse 3's position
        Print Horse 3

    Display the race track

END WHILE

IF Horse 1 has reached position 15
    Print "Horse 1 wins!"

IF Horse 2 has reached position 15
    Print "Horse 2 wins!"

IF Horse 3 has reached position 15
    Print "Horse 3 wins!"

ENDSTART
